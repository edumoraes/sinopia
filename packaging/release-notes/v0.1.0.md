The first release of Sinopia: a local-first whiteboard for Omarchy, drawn
by a native Rust engine, that hands a board to the code agent working beside
it and takes a frame back.

## Install

On Arch and Omarchy, from the AUR:

```sh
yay -S sinopia-bin   # this release, ready made
yay -S sinopia       # this release, built from source
yay -S sinopia-git   # the latest commit, built from source
```

The bar widget, the theme hook and the agent skill come in the package under
`/usr/share/sinopia`, switched off; its install message says how to switch
each one on.

Anywhere else, `sinopia-v0.1.0-x86_64-unknown-linux-gnu.tar.gz` holds the
binary and lays itself out with `sudo sh packaging/install.sh sinopia /`
from inside it. It runs on Wayland with Vulkan, xkbcommon and glibc 2.39 or
newer.

## What is in it

- **Drawing.** An infinite canvas with a pencil fitted to the hand and a
  shelf of brushes of its own — pencil, liner, pen, chisel marker,
  airbrush, rounds and erasers — stamped as nibs, with a pen tablet's
  pressure and tilt. The brush sets you downloaded for Sketchbook come in
  with `sinopia brushes import`, nibs and papers included.
- **Shapes and words.** One shape tool for rectangles, ellipses,
  triangles, diamonds, polygons, stars, lines and arrows, each with a
  fill, a stroke and a bar of its own. A text tool for artistic and frame
  text, styled down to a single word: family, size, bold, italic,
  underline, strike, colour and spacing.
- **Images.** Screenshots and images paste straight onto the board.
- **Layers as a tree.** Groups, blend modes, strength, locks, colour tags,
  a filter, copy and paste between boards, merging, and frames that hold a
  stack of their own.
- **Projects in tabs.** Drafts keep themselves; Save and Open go through
  the desktop's file chooser; recent projects remember a picture of
  themselves; an application menu carries every command and its key; undo
  walks back through every change.
- **The Omarchy theme,** followed as it changes: colours, font, corners.
- **To the agent and back.** `Ctrl+E` sends a selection or a frame to an
  agent running in herdr or tmux — Claude Code, Codex, OpenCode, Gemini CLI
  or Crush — with a line of instruction and any of its skills.
  `sinopia agent` lists, reads and adds frames, `sinopia layer` arranges
  the layers and `sinopia text` writes on the board, each change one step
  you can undo. The bundled skill teaches an agent all three.
