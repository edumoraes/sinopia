The first release of Sinopia: a local-first whiteboard for Omarchy, drawn
by a native Rust engine, that hands a board to the code agent working beside
it and takes a frame back.

## Install

On Arch and Omarchy, from the AUR:

```sh
yay -S sinopia-bin   # this release, ready made
yay -S sinopia       # this release, built from source
yay -S sinopia-git   # the latest commit, built from source
```

The bar widget, the theme hook and the agent skill come in the package under
`/usr/share/sinopia`, switched off; its install message says how to switch
each one on.

Anywhere else, `sinopia-v0.1.0-x86_64-unknown-linux-gnu.tar.gz` holds the
binary. It runs on Wayland with Vulkan, xkbcommon and glibc 2.39 or newer.

## What is in it

- An infinite canvas: a pencil, Sketchbook's 211 brushes with their nibs,
  papers and pressure, erasers, pasted images, selection and undo.
- Layers as a tree: groups, blend modes, strength, locks, colour tags,
  merging, and frames that hold a stack of their own.
- Projects in tabs. Drafts keep themselves, and Save and Open go through the
  desktop's file chooser.
- The Omarchy theme, followed as it changes.
- `Ctrl+E` sends a selection or a frame to an agent running in herdr or
  tmux; `sinopia agent` and `sinopia layer` are the way back.
