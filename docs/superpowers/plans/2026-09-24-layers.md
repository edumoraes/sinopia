# Layers at parity — task list

Groups, names/colours/filter, duplicate/copy/cut/paste, merge (down,
visible, flatten), opacity, lock, multi-select, a tree that expands in
place, kinds that read apart, thumbnails, blend modes, add/delete at the
panel's foot, indentation, a lift that only comes with a drag, panel
selection that selects on the canvas, and a CLI that drives all of it.
Design: `docs/superpowers/specs/2026-09-24-layers-design.md`.

Branch `layers`. Every slice is test first: a failing test, the least
code that passes it, repeat. Commits are atomic and semantic
(`type(scope): subject`). Done means CI green with every item below
implemented and checked in a running window.

## Ground rules

- Pure core, thin shell: `doc`, `tree`, `editor`, `layers`, `menu`,
  `scene`, `select`, `export`, `graft`, `cli`, `ipc` carry the tests;
  `app`, `gfx`, `clipboard` stay thin.
- Every new field is absent on disk at its default: a board written
  before this branch opens meaning what it meant, and one written after
  without the new features reads the same to the old binary.
- `cargo build`, `cargo clippy --all-targets` with zero warnings;
  the WGSL is validated in the suite, not only at the first window.
